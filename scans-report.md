# Cover scan measurements

Generated by `scripts/measure-covers.ts`. Assumes each source image is a single, pre-cropped full wrap (back | spine | front) with no border beyond the trim edge. Fold lines are found by edge detection, not assumed; header bands are detected as either a flat colour or a smooth vertical gradient (by where real cover art/photo texture starts, not by colour alone) — sloped/curved headers still need a follow-up pass. Files whose embedded DPI isn't exactly 300 are rejected outright and don't appear below (see stderr).
